# Bushra Hospitality Presentation

Interactive bilingual web presentation for Bushra Hospitality.

## Live presentation

After GitHub Pages is enabled with **GitHub Actions**, the site will be available at:

https://marwaothman.github.io/bushra-hospitality-presentation/

## Publishing

The workflow in `.github/workflows/pages.yml` builds and deploys the presentation automatically whenever changes are pushed to `main`.

Deployment is configured through GitHub Actions.

Large videos and gallery images are served from the existing Bushra presentation media host to keep this repository lightweight and fast.
